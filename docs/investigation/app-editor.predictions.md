# エディタ調査 — 測る前の宣言(規則 11)

> 基準: main = `42d4a3a`。**この文書は実機を 1 周も回す前に書いた。**
> あとから数字を書き足さない。外れたら「外れた」と書く(規則 16: 期待値を黙って上げない)。

## 何を測るか(計器)

**確保量を主、tick を副**にする(規則 9)。

- 主: `%%HEAP-USED-BYTES` の差分。**同じ窓で `%%GC-COLLECT-COUNT` が動いていないこと**を
  併せて記録する。動いていたらその窓の確保量は読めない(差が縮む/負になる)
- 副: `get-internal-real-time`。**分解能は 10ms(1 tick)**(規則 10)。
  10 tick 未満の差は「無い」とは言わない
- 経路(規則 12): `%%za-compiled-p` で `term-write-at` が JIT 済みかどうかを併記する

床(規則 3): 「同じ回数だけ `term-write-at` を呼ぶが、文字は 0 文字」を別に測る。

## 宣言

| # | 宣言 | 根拠 |
|---|---|---|
| P1 | `term-write-at` は JIT 済み(`t`)である | init.lisp の素の defun で、while と関数呼び出しだけ |
| P2 | 1 行(159 文字)の確保量は **16KB 以下**。1 文字あたり **100 byte 以下** | 文字は即値、確保があるとすれば呼び出しの引数 cons |
| P3 | 全画面(49 行 × 159 文字)の確保量は **1 行の 49 倍 ±20%** に入る | 行ごとに同じ処理をするだけ |
| P4 | 全画面は **10 tick 以上 1000 tick 以下**(0.1〜10 秒)。1 行は **20 tick 以下** | 1 文字あたり画素書き込み約 279 回 × 7791 文字 ≈ 220 万回 |
| P5 | 行の最終桁まで書くと**次の行の先頭へ折り返す**(次の 1 文字は (row+1, 0) に出る) | framebuffer.c の write_char が cols で newline する |
| P6 | **最下行で行送りを出すと格子が 1 行巻き上がる**(最下行に書いた文字が 1 つ上の行で読める) | newline → content_scroll_up |
| P7 | 文字列リテラルは **その場で書き換わり、同じ関数を呼び直しても書き換わったまま**である | set-elt の文字列枝が bytes[idx] を直に書く |
| P8 | 1 文字ずつ `string-append` で 160 文字の行を作ると、`create-string` + `set-elt` より**確保量が 10 倍以上多い** | 連結は毎回新しい文字列を作る(O(n²)) |

## 判定の使い道(先に決めておく)

- **差分再描画が要るか**は P4 と、1 行と全画面の比で決める。
  「全画面が 1 行の 49 倍」であれば、描き直す行数を減らした分だけ素直に効く
- **行の持ち方**は P2(1 文字あたりの確保量)と P8 で決める

## 2 周目の宣言(1 周目の結果を見たあと、2 周目を回す前に書いた)

1 周目で「1 文字あたり約 66 byte 確保する」ことが分かった。確保は
**Lisp から呼ぶ回数に比例する**(引数ごとに cons が 1 つ)と読める。
だとすれば **C の中で 1 文字ずつ流す `(format out "~A" s)`** は、
呼び出しが 1 回で済むぶん桁で安いはずである。**これが成り立つなら C を足さずに済む。**

| # | 宣言 | 根拠 |
|---|---|---|
| Q1 | 全画面を format で書くと、確保量は `term-write-at` の **1/10 以下**(50,000 byte 以下) | 1 行につき Lisp の呼び出しは数回だけ |
| Q2 | format の道は tick でも `term-write-at` 以下(遅くならない) | 画素への書き込み回数は同じ |
| Q3 | 1 行を format で書くと **1,000 byte 以下**(`term-write-at` は 10,704 byte) | 同上 |
| Q4 | ホスト共有の既存ファイルを**短い内容で**開き直して上書きでき、読み返すとちょうど 3 行 | 9P の開きに O_TRUNC がある |
| Q5 | 同じ周の `term-write-at` 全画面は 1 周目と**同じ 505,344 byte** になる | 確保は決定的 |
